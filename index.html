The Problem

Your APIs are running the business. But nobody knows which ones, what they do, or what they cost.

The average enterprise bank operates over 800 production APIs. Ask your CTO to name them all, their owners, their cost, and their consumers. You'll get a pause — and a spreadsheet from 2022.

API gateways manage traffic. Dev portals publish docs. Neither gives you intelligence. EntApiCat does.

🏚️
The Ownership Vacuum
Reorgs happen. Teams disband. APIs stay running — consuming budget, carrying security risk — with nobody accountable. Orphan APIs are universal in any portfolio over 200 APIs.

FAQ

Common questions.

Does EntApiCat replace my API gateway or developer portal? +
No. EntApiCat is an intelligence layer that sits above your existing operational tooling. It integrates with your gateway (Apigee, Kong, MuleSoft, AWS) and reads data from your existing portal. It does not replace or compete with either. Think of it as the business and governance layer your gateway was never designed to provide.
How long does deployment take? +
Most enterprise clients have a populated, synced catalogue within 4 to 6 weeks of contract signature. Full classification and governance framework activation typically takes 10 to 12 weeks. There is no multi-year implementation — this is a SaaS product with pre-built connectors, not a custom build.
Which API gateways do you integrate with? +
We have pre-built connectors for Apigee (Google Cloud), Kong Enterprise, MuleSoft Anypoint, AWS API Gateway, Azure API Management, IBM DataPower, and Axway Amplify. Custom gateway integrations are available for the Sovereign plan. We also support OpenAPI 3.x spec import for any gateway that exports standard specs.
How does the AI redundancy analysis work? +
EntApiCat analyses API names, OpenAPI specs, traffic patterns, and functional domain tags to identify APIs with overlapping capability across business units. It clusters similar APIs, estimates the consolidation savings based on your actual cloud billing data, and generates a prioritised rationalisation roadmap — with specific consolidation recommendations per redundancy group.
Is our API metadata secure? Can we deploy on-premise? +
The Intelligence plan is hosted on ISO 27001-certified, SOC 2 Type II infrastructure with data residency in your chosen region. The Sovereign plan supports fully on-premise or private cloud deployment for regulated institutions including central banks and systemically important financial institutions. All data is encrypted at rest and in transit.
What is the difference between the Platform and Consulting offerings? +
The Platform is an out-of-the-box SaaS product — you deploy it, connect your gateways, and it works. The Consulting offering is for organisations that need a bespoke solution built on their own infrastructure, or that need strategic architecture support before committing to a platform. Many clients start with Consulting for the strategy and taxonomy, then adopt the Platform for ongoing management.
